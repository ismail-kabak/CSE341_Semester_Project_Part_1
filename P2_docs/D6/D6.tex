\section{Workload split}

The division for Part~2 followed the natural module split from the
joint Part-2 plan: \emph{Berk = interpreter + rendering + Part-1
parser carryover}, \emph{İsmail = type checker + Part-1 lexer
carryover}, with the cross-cutting shared modules
(\texttt{environment.py}, \texttt{runtime\_values.py},
\texttt{errors.py}) and the runtime contract drafted and reviewed
jointly per plan~\S2.5 / \S2.6.

\medskip
\noindent The workload is split \textbf{evenly (approximately 50/50)}
between the two partners. Berk's main artefacts -- the
\textasciitilde 700-line interpreter, the rendering layer, the
recursive-descent parser carried over from Part~1, and the
36-test interpreter suite -- are matched on İsmail's side by the
\textasciitilde 700-line type checker (all 19 spec~\S10 errors
implemented, including the \texttt{captured\_params} re-execution
rule for \texttt{scale}), the hand-written lexer carried over from
Part~1, and the late-cycle bug-fix round that resolved several
integration issues uncovered by the PM review. Both partners
contributed to the shared infrastructure and to all five written
deliverables.

\medskip
\noindent Each partner's contribution is comfortably above the 40\%
threshold the handout requires.
