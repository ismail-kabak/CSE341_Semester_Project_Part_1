# DataScript — CSE341 Semester Project Part 1

A domain-specific language for querying tabular data (CSV files).
CSE 341 Course Project — Part 1.

## Requirements

- Python 3.8 or later
- No external libraries required

## Running

```
python main.py <source_file>
python main.py --dump-ast <source_file>
```

## Examples

```
python main.py examples/query_basic.ds
python main.py --dump-ast examples/query_basic.ds
```
